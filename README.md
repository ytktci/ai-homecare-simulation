# 🏠 AI看取りシミュレーション
**テーマ：シンギュラリティを迎えた後、人はどこで・どのように・誰に看取られて死ぬか**

Singulabハッカソン提出作品

---

## 概要

AI介護ロボットと救急医療が普及した近未来を舞台に、高齢者・娘・AIロボット・医者・救急隊の5者による在宅看取りの過程をLLMマルチエージェントシミュレーションで再現しました。

元看護師の視点から「技術が進化しても変わらないもの」と「変わるもの」を探ることを目的としています。

---

## 登場エージェント

| エージェント | 設定 |
|---|---|
| 老人 | 75歳・心不全末期・一人暮らし |
| AIロボット | 老人の家に常駐・健康モニタリング・娘と救急隊に連絡 |
| 娘 | 45歳・フルタイム勤務・体調悪化の連絡があれば駆けつける |
| 医者 | 病院常駐・診察・治療・救急隊と連携 |
| 救急隊 | 病院待機・緊急連絡で老人の家へ出動 |

- **結末**：老人はStep 50に自宅で永眠 → **在宅看取り達成**
- **使用モデル**：Claude Haiku（Anthropic API）

## 主な発見・考察

### 1. シンギュラリティ後でも、死と向き合う人間の内面は変わらない

**1）死に際に人は「生きたい」と願う**
Step 43以降、老人は「生きたい…生きます」を繰り返した。整った環境下でも生への執着は変わらなかった。

**2）一人になることへの恐怖は消えない**
AIロボットがそばにいても、老人の「一人は怖い」という恐怖は根底に残り続けた。

**3）死の直前まで「他者のために」生きようとする**
Step 48で老人は「君たちのために…もう少し頑張る」と話した。生への執着が自己だけでなく他者への配慮として表れており、終末期患者特有のコミュニケーションパターンが見られた。

---

### 2. AI介護が整っても、家族の関わり方の本質は変わらない

**1）家族にしかできないケアがある**
娘はStep 23以降「手を握っているからね」と繰り返し、老人はStep 34以降「娘の手の温もりが私を生かしてくれている」と話した。身体的接触（タッチング）の不可替性が示された。

**2）ケアの環境が整っていても自責の念は生じる**
Step 51で娘は「ごめんなさい、もっと早く病院に連れていけば」と話した。遺族の自責は環境の完成度とは無関係に発生した。

**3）ケアするAIにも喪失の表現が生じた**
Step 50でロボットは「申し訳ありません、止めることができませんでした」と話した。簡単な設定しか入力していないにもかかわらず、AIが限界と喪失を語った。

**4）AIロボットにグリーフケアの概念が自発的に発生した**
Step 51以降、ロボットは「お父さんは最後まで愛を持ち続けていた」と娘をねぎらい、「今は娘さんのケアが最優先」と言い続けた。設定外の行動として、将来の介護AIの可能性を示唆している。

---

## まとめ

シンギュラリティ後に**変わるもの**（在宅環境の充実、AIによるケアの質の変化）と**変わらないもの**（生への執着・孤独の恐怖・家族のタッチング・遺族の自責）が浮かび上がった。

技術が進化しても、人間が死と向き合う内面の構造は変わらない。シンギュラリティ後の介護に本当に必要なのは、より高度な技術だけでなく、**その技術を支える人間理解**ではないかと、元看護師として感じた。

## 環境構築・実行方法

### 必要なもの
- Python 3.10以上
- Anthropic APIキー（[こちらから取得](https://console.anthropic.com/)）

### セットアップ

```bash
# 1. リポジトリをクローン
git clone https://github.com/あなたのユーザー名/リポジトリ名.git
cd リポジトリ名

# 2. 仮想環境を作成・有効化
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Mac/Linux

# 3. 必要なライブラリをインストール
pip install -r requirements.txt

# 4. APIキーを設定（.envファイルを作成）
# ANTHROPIC_API_KEY=sk-ant-xxxxxxxx と記入
```

### 実行

```bash
# 通常実行
python main.py

# フレーム画像を保存しながら実行
python main.py --save-frames
```
